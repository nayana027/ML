# ML
Drone and Bird Classification



This project focuses on classifying images into two categories: Bird and Drone using machine learning and image processing techniques.

The system extracts image features and uses a Probabilistic Neural Network (PNN) to identify whether the given image is a bird or a drone.


Technologies Used:
MATLAB
Machine Learning
Image Processing
Gabor Features
Color Moments
Probabilistic Neural Network (PNN)

Workflow:
Collect bird and drone images.
Preprocess the images.
Extract image features.
Train the PNN classifier.
Test the model with input images.
Display the classification result.

Applications:
Drone detection
Bird monitoring
Airport surveillance
Wildlife protection
